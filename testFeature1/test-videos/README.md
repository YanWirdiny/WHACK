# Place your test MP4 videos in this folder

## Suggested Test Videos:

1. **Street Crossing Scene**
   - Pedestrian at crosswalk
   - Cars approaching
   - Traffic lights

2. **Indoor Navigation**
   - Hallway with obstacles
   - Furniture placement
   - Doorways

3. **Outdoor Scene**
   - People walking
   - Vehicles parked/moving
   - Street signs

## File Size Recommendations:

- Keep videos under 20MB for faster processing
- 5-10 seconds duration is ideal
- 720p or 1080p resolution
- MP4 format (H.264 codec)

## Test Videos Not Included

Add your own test videos here. Videos are ignored by git to keep the repository size small.
